Command Runtime Shape

Worker Accepts CLI request

POST `/__artisan` validates input and forwards it to the command session.

Durable Object Owns process state

Serializes command execution, streams output, and keeps cursor/session state.

D1 Reads app data

Runs command queries and writes command audit rows.

KV + Cache Stores command metadata

Caches recent output and command discovery data near the edge.

R2 Persists artifacts

Stores generated reports, snapshots, and export files.

Queues Continues background work

Dispatches follow-up jobs without blocking the terminal stream.
