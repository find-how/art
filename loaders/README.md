# Pioneer Loading Assets

Standalone animated SVG loaders for AI thinking and background work states.

## Files

| File | Use |
| --- | --- |
| `pioneer-wingbeat-loader.svg` | Primary thinking state. Fast wingbeat with subtle signal trails. |
| `pioneer-signal-loader.svg` | Longer waits, agent routing, or network work. Bird plus rotating signal rings. |
| `pioneer-fold-loader.svg` | Compact loader for inline panels. Sequential origami fold illumination. |

## Usage

```html
<img src="/assets/loaders/pioneer-wingbeat-loader.svg" alt="Pioneer is thinking">
```

The SVGs are transparent, scalable, self-contained, and include a reduced-motion fallback.
