# Investor Pitch

Pioneer is the missing framework layer for Cloudflare's developer platform.

Cloudflare has the primitives: Workers, D1, KV, R2, Queues, Durable Objects, logs, and deploy infrastructure. Pioneer gives developers the full-stack framework experience on top of those primitives.

The wedge is simple: AI can generate application code, but teams still need production-shaped infrastructure. Pioneer turns generated business logic into a running Cloudflare-native app.

The moat is the compiler and TypeGraph-backed framework model. Pioneer can understand routes, providers, middleware, jobs, database access, cache usage, queue dispatches, and deploy targets before the app runs.
