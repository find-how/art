# Status Pills

Status pills should be small, technical, and tied to real state.

## Approved Statuses

- Ready
- AI is writing
- Generated
- Deploy queued
- Compiling
- Bindings inferred
- Wrangler running
- 201 Created
- Observable

## Styling

- Green: success, active Pioneer action, generated or running state.
- Gold: Cloudflare or deploy feedback.
- Blue: logs, response, and observability.
- Neutral: idle, ready, file paths.
