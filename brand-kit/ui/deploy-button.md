# Deploy To Pioneer Button

The Deploy to Pioneer button is a core brand asset. Treat it like Stripe's payment button or Vercel's deploy button.

## Primary Copy

```txt
Deploy to Pioneer
Edge feedback loop
```

## Demo Copy

```txt
Deploy to Pioneer
Wrangler local feedback
```

## Usage

Use it when Pioneer takes code from intent to runnable app:

- generated app previews
- demos
- docs examples
- starter templates
- launch pages
- GitHub README buttons
