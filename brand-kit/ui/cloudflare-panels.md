# Cloudflare Panels

Cloudflare panels are proof surfaces, not decorative co-branding.

## Purpose

Show what Pioneer ran from the generated code:

- Worker route
- bindings
- D1 write
- queue dispatch
- cache write
- local request feedback

## Language

Use "Cloudflare-native" and "Cloudflare-shaped" when describing the target. Use "Wrangler" when showing local execution.

## Guardrail

Do not make the page look like a Cloudflare product. Cloudflare is the platform. Pioneer is the framework layer that maps business logic onto the platform.
