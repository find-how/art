# Approved Language

## Words To Use

- business logic
- generated code
- running app
- Cloudflare-native
- Worker
- D1
- Cache
- Queue
- bindings
- local feedback
- deploy path
- edge infrastructure
- Wrangler
- smoke request

## Words To Use Carefully

- compiler
- DI
- tree-shaking
- nominal identity
- TypeGraph
- proof
- zero-runtime
- formal guarantees

These belong in technical docs and proof sections, not the first brand layer.

## Preferred Claims

- Pioneer turns business logic into Cloudflare-native infrastructure.
- Routes become Workers. DB calls become D1 bindings. Queue dispatches become background jobs.
- Ask AI for the endpoint. Pioneer makes it runnable.
- Write the checkout logic. Pioneer wires the app.

## Claims To Avoid

- Pioneer is a Rust compiler with nominal module identity and compile-time DI.
- Pioneer is Laravel for TypeScript.
- Pioneer is an AI framework.
- Pioneer abstracts infrastructure into a composable developer platform.

The first claim is internal truth. The second can be useful shorthand for technical audiences. The third is misleading. The fourth is too generic.
