# Positioning

## Company

find.how

## Product

Pioneer

## Core Category

Full-stack TypeScript framework for Cloudflare-native applications.

## One-Sentence Positioning

Pioneer is the full-stack TypeScript framework that turns application business logic into production-ready Cloudflare edge infrastructure.

## Short Positioning

Write business logic. Pioneer compiles the infrastructure.

## Market-Facing Wedge

AI can now generate useful application code, but generated code still needs infrastructure. Pioneer closes that gap by turning business logic into a running Cloudflare-shaped app.

## Supporting Proof

Pioneer owns a compiler and TypeGraph-backed model of framework code. That lets it understand routes, providers, bindings, middleware, jobs, and generated entry points before the app runs.

## Do Not Lead With

- Rust compiler internals
- TypeGraph
- dependency injection
- formal proof language
- Laravel comparison
- generic AI framework claims

Those details are real, but they support the claim instead of replacing it.
