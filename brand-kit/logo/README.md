## Usage Rule

The logo appears in three contexts:

1. Framework identity: `Pioneer`
2. Package identity: `@find-how/pioneer`
3. Action identity: `Deploy to Pioneer`

The current mark is a minimum viable bird/leaf/arrow glyph. Long term, it should become more distinctive while preserving the bird, route, compass, deploy arrow, leaf, and edge-network associations.
