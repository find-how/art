# Landing Page Assets

The landing page should make the Demo the first visual proof: ask for an endpoint, show generated TypeScript business logic, then show Pioneer wiring the Worker, D1, Cache, Queue, auth, logs, and Wrangler feedback.

## Files

| File | Use |
|------|-----|
| `landing-page-hero.svg` | Editable hero artwork for launch pages, docs, decks, and social previews. |
| `landing-page-hero.png` | PNG export generated from the hero artwork. |
| `landing-page-copy.md` | Approved copy blocks for the first viewport and proof cards. |

## Rule

Do not lead with framework architecture. Lead with the working app:

```txt
Write business logic. Pioneer wires the Cloudflare app.
```
