## Usage

Use Cloudflare terms when showing the concrete infrastructure Pioneer maps to:

```txt
Route -> Worker
DB -> D1
Cache -> edge cache
Queue -> Queues
```

## Guardrail

Pioneer should not sound like it only wraps Cloudflare. Pioneer is a full-stack framework that targets Cloudflare-native infrastructure.
