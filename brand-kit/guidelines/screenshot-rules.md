# Screenshot Rules

## Use Screenshots That Prove The App Runs

Prioritize:

- generated file path
- code editor with real business logic
- Deploy to Pioneer button
- terminal binding output
- Cloudflare/Wrangler feedback panels
- local smoke request result

## Avoid

- empty dashboards
- abstract architecture screenshots
- decorative animation frames without product proof
- cropped code with no file path

## Required Demo Thumbnail Copy

```txt
AI wrote the endpoint.
Pioneer ran the app.
```
